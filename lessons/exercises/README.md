# Practice tasks

## Beginner
1. Inspect shape, dtypes, and missing counts.
2. Select pickup/dropoff, distance, fare, tip, total.
3. Filter positive distances and sort by fare.
4. Convert miles to kilometers with NumPy.

## Intermediate
5. Normalize payment labels.
6. Calculate trip duration and flag negative durations.
7. Aggregate count, mean, and median fare by payment.
8. Create pickup-borough by payment crosstab.
9. Calculate fare by distance band.
10. Calculate tip percentage only when fare is positive.

## Advanced
11. Add a data-quality rule and unit test.
12. Compare vectorized arithmetic with `apply(axis=1)` on repeated data.
13. Compare memory usage before/after converting a text column to category.
14. Add color-by-payment analysis and document missing categories.
15. Add a custom output directory CLI option.
16. Write three evidence-backed findings and two limitations.
